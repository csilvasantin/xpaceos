AyudaHelp · Gemelo digital de XpaceOSXpaceOS digital twin

Referencia permanente de los comandos del simulador Admira XP (el Digital Twin de XpaceOS). Todos se escriben en la consola Telegram inferior del gemelo y respetan la convención: invocar sin argumentos hace toggle, y los aliases en mayúsculas/minúsculas funcionan igual. Permanent reference for the commands of the Admira XP simulator (the XpaceOS Digital Twin). You type them in the twin's bottom Telegram console, following the convention: calling with no arguments toggles, and upper/lowercase aliases work the same.

Modo Demo — pulsa DEMO en la pantalla 0 para que el simulador ejecute todas las funciones sin tu intervención. También arranca solo si el tótem queda 60s sin tocarse, y vuelve a la pantalla 0 tras 5 minutos. Demo Mode — press DEMO on screen 0 and the simulator runs every feature on its own. It also auto-starts if the totem is idle for 60s, and returns to screen 0 after 5 minutes.
