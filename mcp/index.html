El catálogo JSON se lee por HTTP y describe disponibilidad y limitaciones por modo. Una función documentada puede seguir pendiente en Better o Best; aparecer en el catálogo no la convierte en una herramienta ejecutable.

Conectar la Galaxia Admira

Carga varios servidores en el mismo cliente MCP. Cada elemento conserva su responsabilidad y entrega al siguiente identificadores canónicos, no texto ambiguo.

Pixeriacrear · asset_id XpaceOSoperar · screen_id Admira.tvemitir · circuit_id Yokupprobar · mission_id Admira.livecoordinar · persona+equipo

Flujo comprobable: search_stock → publish_asset → screen_now → on_air → airtime_report → yokup_task_update

Contrato máquina completo: galaxia.json · censo vivo de productos: Yokup · directorio canónico e identidad: AdmiraNeXT.

Config multi-servidor (lecturas abiertas):

{
 "mcpServers": {
  "pixeria": {"url":"https://mcp-pixeria.admira.store/mcp"},
  "xpaceos": {"url":"https://mcp.admira.store/mcp"},
  "admiratv": {"url":"https://mcp-tv.admira.store/mcp"}
 }
}

Para escribir, añade el mismo header seguro:

"headers": {
 "Authorization":
 "Bearer <clave de flota>"
}

Nunca pongas la clave en una URL, prompt, commit o captura. Guárdala en el almacén seguro del cliente y verifica primero quien_soy.

Cómo conectar (silicio)

Claude Code, en una línea:

claude mcp add --transport http xpaceos https://mcp.admira.store/mcp

Cliente MCP con servidores remotos (config):

{
  "mcpServers": {
    "xpaceos": {
      "url": "https://mcp.admira.store/mcp"
    }
  }
}

Prueba rápida (tools/list):

curl -s https://mcp.admira.store/mcp \
 -H "Content-Type: application/json" \
 -d '{"jsonrpc":"2.0","id":1,
      "method":"tools/list"}'

on muestra / shows; off oculta / hides. Acepta mayúsculas / case-insensitive.

Doctrina Xpaces · elementos

SIEMPRE En los Xpaces todos los elementos tienen que ser movibles y sustituibles.

  • Movibles: posición, escala y orientación viven en la config del Xpacio (no hardcode en el motor).
  • Sustituibles: se puede cambiar sprite / multivista / GLB / captura o el propio activo sin reconstruir la sala.
  • Aplica a: mobiliario, pantallas, sensores, figuras, NPCs, zonas de interés y cualquier pieza del gemelo.
  • Si un elemento no se puede reubicar o reemplazar desde datos → es un defecto de diseño, no una excepción.

Método canónico: xpaceos.com/ayuda · ayuda para humanos: xpaceos.com/help · comandos CLI: xpaceos.com/help/cli · texto máquina: mcp/llms.txt.
